Técnico de Suporte Informático

A aprendizagem de HTML ajudou-me a conhecer os elementos necessários para criar uma página web. Com esta linguagem, aprendi a organizar informações através de títulos, textos, imagens e hiperligações. Também compreendi que cada elemento possui uma função na construção e apresentação dos conteúdos de um site.

Com o CSS, aprendi a personalizar as páginas e a torná-las visualmente mais agradáveis. Esta linguagem permite controlar o fundo, as cores, o tamanho dos textos, as margens e as bordas dos elementos. Assim, a combinação de HTML e CSS facilita a criação de páginas organizadas, claras e adequadas às necessidades dos utilizadores.
